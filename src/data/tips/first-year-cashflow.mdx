창업 1년 차에 폐업하는 가장 큰 이유는 **"매출이 없어서"가 아니라 "현금이 떨어져서"**입니다. 매출이 있어도 현금흐름 관리를 못 하면 버틸 수 없습니다.


## 현금흐름이 매출보다 중요한 이유

- 매출은 발생 시점과 입금 시점이 다릅니다 (카드 매출 → D+3~7일 입금)
- 고정비(임대료, 인건비)는 매달 정해진 날에 빠져나갑니다
- **"이번 달 매출은 좋았는데 통장이 비어 있다"**가 현금흐름 문제의 전형적 증상


## 창업 1년 차 자금 관리 원칙

### 1. 월 고정비를 정확히 파악하기

매달 반드시 나가는 돈을 먼저 계산하세요.

| 항목 | 예시 금액 |
|------|----------|
| 임대료 | 150만 원 |
| 인건비 | 200만 원 |
| 공과금 | 30만 원 |
| 대출 이자 | 40만 원 |
| 보험·세금 | 20만 원 |
| **합계** | **440만 원** |

- [**임대료 비율 계산기**](/tools/rent-ratio-calculator)로 매출 대비 임대료가 적정한지 확인
- 임대료는 매출의 **10~15%** 이하가 안전합니다.

### 2. 손익분기점 매출 확인

고정비를 알면 **최소 얼마를 벌어야 하는지** 계산할 수 있습니다.

- [**손익분기점 계산기**](/tools/break-even-calculator)에 고정비와 마진율을 입력
- 손익분기점 매출을 **일 매출로 환산**해서 매일 체크하는 습관이 중요

### 3. 비상 운영 자금 확보

창업 초기에는 **최소 3개월분 고정비**를 현금으로 보유해야 합니다.

- 위 예시 기준: 440만 원 × 3개월 = **1,320만 원**
- 이 돈은 절대 다른 용도로 쓰지 마세요
- 매출이 예상보다 낮을 때 버틸 수 있는 시간을 벌어줍니다

### 4. 대출 상환 전략

창업 자금 대출이 있다면 **상환 계획을 반드시 세우세요.**

- [**대출 상환 계산기**](/tools/loan-calculator)로 월 상환액과 총 이자를 확인
- 원리금 균등 상환이 초기 부담은 크지만, 총 이자는 적습니다
- 매출이 안정되기 전까지는 **거치 기간**을 활용하는 것도 방법

### 5. 통장 분리 운영

사업용 통장을 **최소 3개**로 분리하면 현금흐름이 눈에 보입니다.

| 통장 | 용도 |
|------|------|
| 매출 통장 | 카드·현금 매출 입금 전용 |
| 고정비 통장 | 임대료·인건비·공과금 자동이체 |
| 비상금 통장 | 3개월 운영비 예치, 손대지 않기 |


## 월별 현금흐름 체크리스트

매월 1일에 아래 항목을 점검하세요.

- [ ] 전월 매출 총액 확인
- [ ] 전월 고정비 총액 확인
- [ ] 순이익(매출 - 고정비 - 변동비) 계산
- [ ] 비상금 통장 잔액 확인
- [ ] 다음 달 대출 상환액 확인
- [ ] 카드 매출 미입금분 확인
