테이블 회전율은 하루 동안 한 테이블에 몇 팀의 손님이 앉았는지를 나타내는 수치입니다. 같은 면적, 같은 좌석 수에서도 회전율에 따라 매출이 2~3배 차이날 수 있습니다.


## 테이블 회전율 계산법

**회전율 = 하루 총 손님 수 / 총 좌석 수**

예를 들어 20석짜리 매장에 하루 60팀이 방문했다면 회전율은 3.0입니다. 일반적인 기준은 다음과 같습니다.

- **카페**: 2~4회전 (장시간 체류 특성)
- **일반 음식점**: 3~5회전
- **분식/패스트푸드**: 5~8회전
- **고급 레스토랑**: 1.5~2.5회전


## 회전율 높이는 5가지 방법

### 1. 주문~서빙 시간 단축

주방 동선 최적화가 핵심입니다. 메뉴가 30가지라면 20가지로 줄이는 것만으로 조리 시간이 크게 단축됩니다. 사전 준비(미장플라스) 비율을 높이면 피크타임 대응력이 올라갑니다.

### 2. 테이블 세팅 자동화

손님이 나간 후 다음 팀이 앉기까지의 시간을 **턴오버 타임**이라고 합니다. 목표는 5분 이내입니다.

- 식기 종류 최소화 (세팅 표준화)
- 버스보이 역할 지정 (전담 정리)
- 테이블 청소 도구 가까운 곳 배치

### 3. 메뉴 구성 최적화

조리 시간이 긴 메뉴와 짧은 메뉴를 섞어 구성하세요. 피크타임에는 빠른 메뉴 위주로 추천하는 것도 방법입니다.

- **세트 메뉴 도입**: 주문 시간 단축 + 객단가 유지
- **사이드 메뉴 간소화**: 선택지를 줄여 의사결정 시간 단축

### 4. 예약 시스템 활용

예약제를 도입하면 대기 손님 관리가 쉬워지고, 빈 테이블 시간을 최소화할 수 있습니다. 네이버 예약이나 캐치테이블 같은 무료·저가 솔루션을 활용하세요.

### 5. 좌석 배치 재설계

2인석과 4인석 비율을 실제 방문 인원 데이터에 맞춰 조정하세요. 2인 손님이 70%인 매장에서 4인석 위주로 배치하면 좌석 낭비가 심합니다.


## 주의: 객단가와의 균형

회전율만 높이면 손님이 불편해합니다. "빨리 먹고 나가라"는 분위기는 재방문율을 떨어뜨립니다.

- 디저트·음료 추천으로 객단가를 올리면 회전율이 약간 낮아져도 매출은 유지됩니다
