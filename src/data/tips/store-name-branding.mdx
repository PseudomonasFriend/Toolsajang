가게 이름은 **첫인상이자 마케팅의 시작**입니다. 좋은 상호명 하나가 간판, 배달앱, 네이버 검색에서 모두 유리하게 작용합니다. 이름 하나 잘 지으면 광고비를 아낄 수 있습니다.


## 좋은 가게 이름의 3가지 조건

### 1. 짧고 발음하기 쉬울 것

- **3~5글자**가 가장 기억에 남습니다.
- 입으로 말했을 때 자연스러운 이름이 좋습니다.
- 나쁜 예: "프레시 오가닉 그린 델리" (너무 길고 발음이 복잡)
- 좋은 예: "풀밭", "달빛식탁", "봄이네"

### 2. 업종이 연상될 것

이름만 듣고 **무슨 가게인지 감이 오면** 최고입니다. 검색에서도 유리합니다.

- "빵굼터" → 베이커리
- "국밥일번지" → 국밥집
- 추상적인 이름은 브랜딩 비용이 더 많이 듭니다.

### 3. 검색에 유리할 것

네이버·구글에서 **가게 이름을 검색했을 때 바로 나오는지**가 중요합니다.

- 너무 흔한 단어("맛집", "카페")만으로는 검색 상위 노출이 어렵습니다.
- 고유한 조합을 만들되, 업종 키워드를 포함하면 좋습니다.


## 상호명 짓기 실전 과정

### Step 1: 아이디어 확보

업종·컨셉·키워드를 정리한 뒤, [**가게명 아이디어 도구**](/tools/shop-name-ideas)로 AI 추천을 받아보세요. 한 번에 최대 15개까지 후보를 생성할 수 있습니다.

### Step 2: 후보 선별

추천받은 이름 중에서 다음 기준으로 걸러냅니다.

- 발음이 자연스러운가?
- 간판에 썼을 때 보기 좋은가?
- 배달앱에서 잘 잘리지 않는 길이인가? (배달앱 표시 제한 확인 — [**글자수 카운터**](/tools/character-counter) 활용)

### Step 3: 상표·상호 중복 확인

**반드시 확인해야 할 곳**:

1. **특허청 KIPRIS** (kipris.or.kr): 등록 상표 검색
2. **네이버 지도**: 동일 상권 내 같은 이름 확인
3. **사업자등록 시 상호 중복**: 관할 세무서에서 확인 가능

같은 이름이 이미 상표 등록되어 있으면 **사용 중지 요청을 받을 수 있으므로** 반드시 사전에 확인하세요.

### Step 4: 간판·로고 시뮬레이션

이름이 확정되면 **간판 목업**을 만들어 보세요. 실제 간판 크기에서 가독성이 떨어지는 이름은 피해야 합니다.

- 영문 혼용 시: 한글·영문 모두 읽기 쉬운지 확인
- 야간 조명 상태에서도 잘 보이는지 고려


## 피해야 할 실수

| 실수 | 문제 |
|------|------|
| 너무 긴 이름 | 간판·배달앱에서 잘림 |
| 유행어 사용 | 유행이 지나면 촌스러워짐 |
| 외국어 남발 | 발음·기억이 어려움 |
| 동일 상호 무시 | 상표권 분쟁 위험 |

가게 이름은 한 번 정하면 바꾸기 어렵습니다. 충분히 후보를 확보하고 신중하게 결정하세요. [**가게명 아이디어 도구**](/tools/shop-name-ideas)로 다양한 후보를 만들어 보는 것부터 시작해 보세요.
