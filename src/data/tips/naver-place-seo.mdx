"성수동 카페", "강남 맛집"을 검색하면 네이버 지도에 가게 목록이 뜹니다. 여기서 상위에 노출되면 별도 광고비 없이도 신규 손님을 꾸준히 유치할 수 있습니다.


## 네이버 플레이스란?

네이버에서 운영하는 지역 비즈니스 등록 서비스입니다. 네이버 지도, 네이버 검색 결과의 "플레이스" 영역에 가게 정보가 표시됩니다.

등록은 무료이며, **네이버 스마트플레이스** (smartplace.naver.com)에서 사업자 등록 후 바로 이용할 수 있습니다.


## 상위 노출의 5가지 핵심 요소

### 1. 기본 정보 100% 채우기

네이버는 정보 완성도가 높은 가게를 우선 노출합니다.

- **영업시간**: 요일별 상세 입력 (브레이크타임 포함)
- **메뉴/가격**: 전체 메뉴 + 가격 등록 (가격 미등록 시 노출 불리)
- **편의시설**: 주차 가능, 반려동물 동반, 키즈존 등 해당 항목 모두 체크
- **가게 소개**: 200자 이상, 핵심 키워드 포함해서 작성


### 2. 사진 등록 (최소 10장)

사진이 많고 퀄리티가 높을수록 노출이 유리합니다.

- **대표 사진**: 외관 + 시그니처 메뉴 (밝고 선명하게)
- **메뉴 사진**: 주력 메뉴 5개 이상
- **매장 내부**: 좌석, 인테리어, 분위기
- **업데이트 주기**: 월 1회 이상 새 사진 추가 (활성 가게로 인식)


### 3. 리뷰 관리

리뷰 수와 평점이 노출 순위에 큰 영향을 줍니다.

- **리뷰 유도**: 계산 시 "리뷰 남겨주시면 다음 방문 시 음료 서비스" 안내
- **답글 달기**: 모든 리뷰에 24시간 내 답글 (부정 리뷰에도 정중하게)
- **영수증 리뷰**: 실제 방문 인증 리뷰는 가중치가 높음

답글 작성 시 매장명·지역명을 자연스럽게 포함하면 키워드 효과도 있습니다.


### 4. 키워드 최적화

손님이 검색할 만한 키워드를 가게 소개·메뉴명에 자연스럽게 녹이세요.

- "성수동 브런치 카페" → 가게 소개에 "성수동에 위치한 브런치 카페"
- "강남역 회식 맛집" → 메뉴에 "회식 코스" 등록
- 네이버 키워드 도구 (searchad.naver.com)에서 월간 검색량 확인 가능


### 5. 예약/주문 기능 활성화

네이버 예약, 네이버 주문을 연동하면 플랫폼 내 활성도가 올라가 노출에 유리합니다. 수수료가 부담되면 예약만 활성화해도 효과가 있습니다.


## 피해야 할 실수

- **허위 리뷰 작성**: 네이버가 감지하면 노출 페널티, 최악의 경우 등록 삭제
- **키워드 남용**: 가게 소개에 키워드를 부자연스럽게 나열하면 역효과
- **정보 미갱신**: 실제 영업시간과 등록 정보가 다르면 사용자 신고 → 신뢰도 하락
