창업 실패의 가장 큰 원인 중 하나가 잘못된 입지 선택입니다. 감으로 고른 자리보다 데이터로 검증한 자리가 훨씬 안전합니다. 무료 도구만으로도 충분한 상권 분석이 가능합니다.

## 무료 상권 분석 도구 4가지

### 1. 소상공인 마당 (sg.sbiz.or.kr)

소상공인진흥공단이 운영하는 공식 상권 분석 서비스입니다.

- **제공 정보**: 업종별 점포 수, 매출 추이, 유동인구, 거주인구, 직장인구
- **사용법**: 지도에서 분석할 위치 클릭 → 업종 선택 → 리포트 자동 생성
- **유용한 지표**: 개업률·폐업률 (높으면 위험 신호), 월별 매출 계절성

### 2. 국토교통부 실거래가 공개시스템 (rt.molit.go.kr)

주변 상가 임대료 시세를 확인할 수 있습니다. 건물주가 제시한 임대료가 적정한지 비교하세요.

### 3. 카카오맵·네이버지도 경쟁점 분석

지도 앱으로 반경 500m 내 동종 업종 수를 직접 세어봅니다.

- 카카오맵에서 업종 검색 후 "지도 보기" → 핀 밀집도 확인
- 리뷰 수·평점도 경쟁 강도 판단에 활용

### 4. 서울 열린데이터광장 (data.seoul.go.kr)

서울 한정이지만 버스·지하철 승하차 인원, 생활인구 데이터를 무료로 제공합니다.

## 현장 조사 체크리스트

데이터만으로는 부족합니다. 반드시 현장을 3번 이상 방문하세요.

- [ ] **평일 점심** — 직장인 유동인구 확인
- [ ] **주말 낮** — 가족·커플 유동인구 확인
- [ ] **저녁 7~9시** — 퇴근 후 유동인구 확인
- [ ] **경쟁점 방문** — 메뉴·가격·손님 수 직접 확인
- [ ] **주차 환경** — 대형마트·주차장 거리

## 피해야 할 입지 신호

- 최근 1년 내 같은 업종 2회 이상 폐업한 자리
- 보증금 대비 월세 비율이 주변 평균의 1.5배 이상
- 3개월 이상 공실로 비어있던 곳 (이유가 있음)
- 대로변이지만 이면도로 진입 차단 구조
