매장 위치가 장사의 절반을 결정합니다. "여기 사람 많아 보이니까"로 결정하면 높은 확률로 후회합니다. 데이터를 기반으로 위치를 분석하는 방법을 단계별로 정리합니다.


## 1단계: 상권 유형 파악하기

상권은 크게 세 가지로 나뉘며, 업종과의 궁합이 다릅니다.

| 상권 유형 | 특징 | 적합 업종 |
|-----------|------|----------|
| **역세권·번화가** | 유동인구 최다, 임대료 최고 | 테이크아웃 카페, 프랜차이즈, 편의점 |
| **오피스 상권** | 평일 점심·저녁 집중, 주말 한산 | 점심 식당, 직장인 카페, 헬스장 |
| **주거 상권** | 저녁·주말 집중, 단골 비율 높음 | 동네 식당, 세탁소, 미용실, 학원 |

### 흔한 실수: "유동인구가 많으면 무조건 좋다"

유동인구가 많아도 **내 고객이 아니면 의미가 없습니다**. 대학가에 고급 레스토랑을 열거나, 오피스 상권에 키즈카페를 여는 것은 유동인구와 타겟 고객이 일치하지 않는 전형적인 실수입니다.


## 2단계: 유동인구 데이터 분석

감으로 "사람 많다"를 판단하지 말고, **데이터로 확인**하세요.

### 무료 데이터 소스

- **소상공인시장진흥공단 상권정보시스템** (sg.sbiz.or.kr): 행정동별 유동인구, 매출 추정, 업종 밀집도
- **서울 열린데이터광장** (data.seoul.go.kr): 서울시 생활인구, 유동인구 통계
- **KT 빅데이터 플랫폼**: 통신 데이터 기반 유동인구 분석
- **네이버 지도 / 카카오맵**: 주변 상점 밀집도, 리뷰 수로 상권 활성도 추정

### 직접 현장 조사 (필수)

데이터만으로는 부족합니다. **최소 3일, 다른 시간대에 직접 가 보세요**.

| 체크 항목 | 확인 방법 |
|-----------|----------|
| 평일 점심 유동인구 | 12시~13시 30분, 매장 앞 통행량 세기 |
| 평일 저녁 유동인구 | 18시~20시, 퇴근 후 통행량 |
| 주말 유동인구 | 토·일 점심~저녁 |
| 유동인구의 성별·연령대 | 내 타겟 고객과 일치하는지 |
| 통행 방향 | 어느 쪽에서 어느 쪽으로 이동하는지 (입구 방향 중요) |

30분 동안 매장 앞을 지나가는 사람 수를 세면 대략적인 일일 유동인구를 추산할 수 있습니다.


## 3단계: 경쟁점 분석

주변 경쟁 상황을 모르고 오픈하면 레드오션에 뛰어드는 꼴입니다.

### 확인할 것들

**같은 업종 경쟁점 수**
- 반경 300m 이내에 같은 업종이 몇 개인지 확인
- 네이버 지도에서 "카페", "한식" 등으로 검색하면 바로 파악 가능

**경쟁점의 상태**
- 리뷰 수와 평점 (높은 평점의 인기 매장이 있으면 신규 진입이 어려움)
- 영업 시간과 메뉴 구성
- 가격대

**경쟁 강도 판단 기준**

| 상황 | 판단 |
|------|------|
| 같은 업종 0~1개 | 수요가 있다면 기회 (수요 자체가 없을 수도 있으니 확인 필수) |
| 같은 업종 2~3개 | 적정 경쟁. 차별화 포인트 필요 |
| 같은 업종 5개 이상 | 과밀. 진입 재고 필요 |

### 보완재 매장은 오히려 플러스

경쟁점은 부담이지만, **보완재 매장은 시너지**를 냅니다. 예를 들어 카페 옆에 베이커리, 음식점 옆에 카페가 있으면 고객이 자연스럽게 이동합니다.


## 4단계: 임대료 대비 매출 가능성 계산

좋은 자리는 비쌉니다. 핵심은 **"이 임대료를 내고도 남는 장사가 되는가"**입니다.

### 매출 추정 방법

**방법 1: 유동인구 기반 추정**
- 일일 유동인구 x 입점율(1~5%) x 객단가 = 일 매출 추정
- 예: 하루 유동인구 2,000명 x 입점율 3% x 객단가 8,000원 = 일 매출 48만 원

**방법 2: 경쟁점 벤치마킹**
- 주변 비슷한 가게의 리뷰 수, 영업 시간, 좌석 수에서 대략적인 매출 추정 가능
- 배달앱에서 리뷰 수 / 영업 개월 수 = 월 주문 수 추정

### 임대료 비율 체크

추정 매출 대비 임대료가 **10~15% 이내**인지 확인하세요. 임대료가 매출의 20%를 넘으면 수익이 어렵습니다.

예를 들어 월 매출을 1,200만 원으로 추정했다면:
- 임대료 120만 원 (10%) → 안전
- 임대료 180만 원 (15%) → 주의
- 임대료 250만 원 (20.8%) → 위험

툴사장 [**임대료 비율 계산기**](/tools/rent-ratio-calculator)에 예상 매출과 임대료를 넣으면 바로 확인할 수 있습니다.


## 5단계: 매장의 물리적 조건 확인

위치가 좋아도 매장 자체의 조건이 나쁘면 문제입니다.

- **가시성**: 간판이 잘 보이는가? 지하나 2층 이상은 가시성이 크게 떨어짐
- **접근성**: 주차 가능 여부, 대중교통 접근성
- **층수**: 1층이 압도적으로 유리. 2층은 임대료 30~50% 저렴하지만 매출도 그만큼 줄어듬
- **전면 폭**: 매장 전면이 넓을수록 노출이 잘 됨
- **배수·환기·전기 용량**: 식음료업은 필수 확인 (나중에 공사하면 비용 폭증)

여러 후보지를 비교할 때는 **평당 임대료**로 환산하면 공정하게 비교할 수 있습니다. 툴사장 [**평당 임대료 계산기**](/tools/rent-per-pyeong)로 빠르게 계산해 보세요.


## 위치 선정 체크리스트

최종 결정 전에 아래 항목을 모두 확인하세요.

- [ ] 상권 유형과 내 업종이 맞는가?
- [ ] 유동인구 데이터를 확인했는가? (온라인 + 현장)
- [ ] 유동인구 중 내 타겟 고객 비율은 충분한가?
- [ ] 반경 300m 경쟁점을 조사했는가?
- [ ] 추정 매출 대비 임대료 비율이 15% 이내인가?
- [ ] 매장 가시성, 접근성, 층수가 적절한가?
- [ ] 설비 조건 (배수, 환기, 전기)을 확인했는가?

매장 위치는 한 번 정하면 쉽게 바꿀 수 없습니다. **감이 아닌 데이터**로, **희망이 아닌 숫자**로 판단하세요.
