# 시급 계산기 (hourly-wage-calculator)

## 개요

시급·일근무시간·주근무일수를 입력하면 일급, 주급, 주휴수당, 월 통상임금, 4대보험 공제액, 실수령액, 사업주 총 인건비를 자동 계산한다.

## 입력

| 필드 | 타입 | 범위 | 설명 |
|------|------|------|------|
| hourlyWage | number | 1원 이상 | 시급 (원) |
| dailyHours | number | 1~12 (0.5 단위) | 1일 근무시간 |
| weeklyDays | number | 1~6 | 주 근무일수 |

## 출력 계산 로직

### 기본 급여
- 주 소정근로시간 = 1일 근무시간 × 주 근무일수
- 일급 = 시급 × 1일 근무시간
- 주급(기본) = 일급 × 주 근무일수

### 주휴수당
- 조건: 주 소정근로시간 ≥ 15시간
- 주휴수당 = 시급 × (주 소정근로시간 ÷ 5)
- 주급(주휴 포함) = 주급(기본) + 주휴수당

### 월 통상임금
- 월 통상임금 = (주급 + 주휴수당) × 4.345
- 월 근로시간 = (주 소정근로시간 + 주휴시간) × 4.345

### 4대보험 (월 소정근로시간 60시간 이상 의무가입)

2025년 기준 요율:

| 항목 | 근로자 | 사업주 |
|------|--------|--------|
| 국민연금 | 4.5% | 4.5% |
| 건강보험 | 3.545% | 3.545% |
| 장기요양 | 건강보험료 × 12.95% | 건강보험료 × 12.95% |
| 고용보험 | 0.9% | 1.15% (10인 미만) |

- 총 인건비 = 월 통상임금 + 사업주 부담 합계

### 최저시급
- 2025년 기준: 10,030원
- 입력 시급이 최저시급 미만이면 경고 표시
