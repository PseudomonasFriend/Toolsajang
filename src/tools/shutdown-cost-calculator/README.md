# 폐업비용 계산기

폐업 시 발생하는 예상 비용과 실질 손실액을 계산합니다.

## 계산 항목

- **원상복구비**: 보증금의 N%를 원상복구 비용으로 산정
- **권리금 손실**: 권리금 회수 불가 시 손실액
- **재고 처리 손실**: 남은 재고 중 회수하지 못하는 금액
- **설비/인테리어 철거비**: 철거 및 처분 비용
- **직원 퇴직금**: 근속 1년 이상 직원의 퇴직금 (월급 × 근속연수)
- **임대차 해지 위약금**: 계약 기간 중 해지 시 위약금
- **기타 비용**: 그 외 폐업 관련 비용

## 결과

- **총 폐업비용**: 위 항목의 합산
- **보증금 반환액**: 보증금에서 원상복구비를 제한 금액
- **실질 손실액**: 총 폐업비용 - 보증금 반환액
