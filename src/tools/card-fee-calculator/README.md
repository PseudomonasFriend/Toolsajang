# 카드수수료 계산기

## 개요
월 카드매출을 기준으로 카드사별 수수료율과 수수료 금액, 실수령액을 계산합니다.

## 입력
- **월 카드매출** (필수): 원화 금액
- **업종**: 일반 / 음식점 / 편의점
- **사업자 유형**: 일반과세자 / 간이과세자 / 면세사업자

## 출력
- 카드사별 수수료율 및 월 수수료 금액 (8개 카드사)
- 평균 수수료율
- 월 수수료 합계
- 실수령액
- 소상공인 우대수수료율 적용 여부

## 계산 로직
- 연매출 = 월매출 × 12
- 연매출 3억 이하: 소상공인 우대수수료율 (0.5~0.8%) 적용
- 연매출 3억 초과: 일반 수수료율 (1.7~2.0%) 적용
- 2024년 기준 카드사별 수수료율 적용

## UI
- 모바일 퍼스트 (max-width: 480px)
- 업종/사업자유형은 버튼 그룹으로 선택
- 카드사별 수수료 상세 표시
- 소상공인 우대수수료 안내 테이블
