# 배달 순이익 계산기

## 개요
배달앱 주문에서 수수료·원가·배달비를 차감한 실제 순이익과 순이익률을 계산합니다.

## 입력
- **주문금액** (필수): 원화 금액
- **배달앱**: 배달의민족 / 요기요 / 쿠팡이츠 (선택 시 기본 수수료율 자동 적용)
- **수수료율**: 기본값 배달앱별 상이, 직접 수정 가능
- **배달비 사장님 부담금**: 원화 금액
- **원가율**: 기본값 35%

## 출력
- 앱 수수료 금액
- 결제 수수료 (PG 3.3%)
- 원가 금액
- 배달비 부담금
- 총 차감액
- 실수령액
- 순이익
- 순이익률
- 진단 메시지

## 계산 로직
- 앱 수수료 = 주문금액 × 수수료율
- PG 수수료 = 주문금액 × 3.3%
- 원가 = 주문금액 × 원가율
- 순이익 = 주문금액 - 앱수수료 - PG수수료 - 원가 - 배달비
- 배달앱별 기본 수수료: 배민 6.8%, 요기요 12.5%, 쿠팡이츠 9.8% (2024 기준)

## UI
- 모바일 퍼스트 (max-width: 480px)
- 배달앱 버튼 그룹 선택 시 수수료율 자동 반영
- 차감 내역 항목별 표시
- 배달앱별 수수료 비교 테이블
