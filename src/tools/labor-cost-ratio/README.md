# 인건비 비율 계산기

## 개요
월 매출과 직원 급여를 기반으로 인건비 비율, 4대보험 사업주 부담금, 업종별 적정 비율 비교를 제공합니다.

## 입력
- **월 매출** (필수): 원화 금액
- **직원 목록**: 복수 직원 추가 가능
  - 급여 유형: 시급 / 월급 선택
  - 급여 금액 (필수)
  - 주당 근무시간 (시급일 때만)
- **4대보험 포함 여부**: 토글

## 출력
- 직원별 월급 (시급→월급 환산 포함)
- 총 급여 합계
- 4대보험 사업주 부담금 (국민연금 4.5%, 건강보험 3.545%, 장기요양 12.95%, 고용보험 0.9%, 산재 1.47%)
- 총 인건비
- 매출 대비 인건비 비율
- 업종별 적정 비율 비교 (음식점 25~30%, 카페 20~25%, 소매 15~20%)

## 계산 로직
- 시급→월급: 주휴수당 포함 (주 15시간 이상), 4.345주 기준
- 4대보험: 각 항목별 사업주 부담률 적용
- 진단: 25% 이하 양호, 25~35% 보통, 35% 초과 위험

## UI
- 모바일 퍼스트 (max-width: 480px)
- 직원 추가/삭제 가능
- 시급/월급 토글
- 4대보험 토글 스위치
